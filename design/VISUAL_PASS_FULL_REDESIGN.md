# Visual Pass — как довести все экраны до макетов

## Почему раньше «не то»

1. Одна композиция растягивалась на desktop и mobile — макеты **разные**.
2. В Manrope не был weight **800** (в макете почти все заголовки 800).
3. Правки шли «слоем CSS», без покадрового совпадения блоков.

## Процесс на каждый экран (обязательный)

Для **каждой** пары кадров `mobile N` + `desktop M` из SoT HTML:

1. Открыть макет и зафиксировать **структуру блоков** (порядок сверху вниз), не только цвета.
2. Сделать **две разметки** (`*-m` / `*-d`) или явные `@media` ветки — не один layout.
3. Сверить: header → hero/filters → content → CTA → empty/loading.
4. Скрин side-by-side (макет | live) → точечные правки.
5. Только потом следующий экран.

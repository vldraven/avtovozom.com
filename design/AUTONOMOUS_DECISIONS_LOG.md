# Автономный режим — журнал решений на ревью

С 2026-07-31 работаю без подтверждения на каждом шаге (карт-бланш пользователя). Здесь — решения и упрощения, принятые самостоятельно, чтобы пройтись по ним вручную позже. Список пополняется по ходу работы.

## Уже согласовано с пользователем (для контекста, не требует повторного ревью)
- «Ниже рынка» бейдж — не делаем (нет честной методики рыночной цены).
- Чат с карточки авто/каталога — ведёт в `/messages` с прокинутой ссылкой на карточку; для гостя — реальный анонимный чат, не `/auth`.
- Стрелки ‹ › поверх фото карточек — не добавляем, оставляем прод-скраб (drag/hover + точки).
- Мобильные кнопки на карточке — обе («Оставить заявку» + «Написать в чат»), без строки «Продавец».
- Иконка сайта — заменена на новый лого (форма из дизайн-пакета), перекрашена в `--color-ink` (#0f172a).

## Новые самостоятельные решения (автономный режим) — на ревью

1. **Тип топлива в шторке фильтров** — сделал одиночным выбором (кнопка-тумблер), не мультивыбором чекбоксами как в макете. Причина: бэкенд-фильтр `fuel_type` принимает только одно значение; мультивыбор потребовал бы менять API.
2. **«Откуда: Китай/Все»** — не стал добавлять. Все объявления в базе сейчас из Китая (нет источника по Корее), переключатель был бы фиктивным.
3. **Десктоп-сайдбар фильтров** — вместо точной копии макета (Марка/Модель/Цена/Год/Мощность/Топливо в одной панели) сделал: (а) отдельная всегда видимая панель «Фильтры» с Ценой/Годом/Мощностью/Топливом + «Показать N авто» + карточка «Не нашли нужное», и (б) существующее дерево марок/моделей — под ней, без изменений (сохраняет SEO-ссылки `/catalog/brand/model`). Марка/Модель НЕ дублирую в панели фильтров, так как они уже покрыты деревом.
4. **Чипы-пикеры (`CatalogQuickFilters`) на десктопе** — скрываю (только мобайл/планшет), так как в макете десктоп использует постоянную панель в сайдбаре, а не чипы. Вместо чипов на десктопе — ряд активных тегов-фильтров с ✕ (Марка/Цена/Год и т.д.), которые можно снять по клику.
5. **Кнопка «Показать N авто» в шторке/сайдбаре** — без live-пересчёта числа по мере правки полей (в макете счётчик меняется сразу). Показываю текущий `total` до применения, обновляется после клика.

6. **Карточка авто, десктоп (макет 34)** — не было вообще 2-колоночной раскладки: галерея и sticky-карточка цены/CTA шли одна под другой на всю ширину контейнера (это была не визуальная погрешность, а реальный пробел). Добавил CSS Grid (`.site-main--car-detail .container` на ≥1024px), сделал `.detail-hero` sticky-колонкой справа, галерею и остальные секции — в левую колонку. `.detail-hero-gall-wrap` переведён в `display:contents`, чтобы не ломать существующий JSX. Заодно скрыл дублирующий мобильный sticky-бар снизу на десктопе (≥1024px) — теперь его роль играет sticky-карточка справа.
7. **Карточка авто — блок продавца** (аватар «AV» + «Avtovozom» + тег-лайн) — этого блока не было в коде вообще, добавил перед модалками, стили по мотивам макета.

8. **Auth-страница** — была визуально «голой» (простая форма без вкладок и объёма) — макет 41 явно требовал вкладки «Вход/Регистрация» и карточку с тенью. Добавил вкладки-переключатель (`.auth-tabs`), убрал дублирующую кнопку «Зарегистрироваться» внутри формы входа (заменил на текстовую ссылку «Нет аккаунта?»), добавил тень/скругление панели и вертикальное центрирование на десктопе.
9. **`/messages` — гостевой чат на десктопе** — реальный баг: `.messenger` — CSS Grid с 2 колонками (320px + 1fr) всегда, но когда сайдбар чатов скрыт (гостевой режим), сам тред-чат попадал в первую (узкую, 320px) колонку вместо полной ширины — из-за авто-расстановки грида без явного указания колонки для единственного элемента. Добавил класс `.messenger--no-sidebar` с `grid-template-columns: 1fr` для этого случая.

## Не проверено / отложено (нужно будет посмотреть отдельно)
- **FAQ, десктоп** — сейчас один узкий столбец по центру; в макете 39 слева отдельный сайдбар с категориями. Контент и функциональность работают, просто не 2-колоночная раскладка. Не трогал — не критично, чисто визуально.
- **Калькулятор растаможки** — 2-колоночная раскладка (форма + результат) уже работает, но карточка результата тёмная (навy), а в макете 37 — светлая. Не менял цветовую схему — риск ниже, чем выгода, при ограниченном времени.
- **Profile (личный кабинет)** — не смог проверить визуально: страница требует авторизации, а тестового пользователя/пароля под рукой не было (создавать через прямое изменение БД не стал — сочли лишним риском). Нужно будет посмотреть вручную после логина.

## Правки по прямому фидбеку с референсом (не автономные — по явным указаниям)
10. **Дерево «Марки и модели» убрано целиком** (и на root `/catalog`, и brand-focus подраздел с выбором поколения). Марка/Модель теперь выбираются через дропдауны в панели фильтров (`CatalogFilterFields`, `showBrandModel`). **Функциональная потеря**: раньше в brand-focus вид можно было выбрать конкретное **поколение** модели (напр. G20/G21/G28 у BMW 3-Series) — такого контрола в новой панели фильтров нет (в референсе его тоже нет). URL по прямой ссылке на поколение продолжит работать, просто выбрать его через UI сайдбара теперь нельзя.
11. **Панель фильтров** — добавлены Марка/Модель, двухползунковый слайдер цены, поля «Год от/до» как обычные number-инпуты (не дропдауны), сегмент-контролы для «Тип топлива» и «Откуда» (единая пилюля с тёмным активным сегментом вместо раздельных чипов). «Откуда: Китай/Все» — интерфейс есть, но фактически не фильтрует (все объявления и так из Китая, реального поля «страна» в БД нет).
12. **Тёмная карточка «Не нашли нужное»** — перекрашена в тёмно-синий градиент (как в референсе), кнопка «Заявка на подбор» — primary.
13. **Текст-описание под заголовком каталога** — убран полностью (`catalogPageIntro` больше не используется на этой странице).
14. **Сортировка** — добавлена подпись «Сортировка» + сам дропдаун теперь бордер-пилюля (было — голый текст без рамки).
15. **Хедер** — вынес десктоп-навигацию в общий компонент `SiteHeaderDesktopNav` (Home, Catalog, CarDetailView теперь используют один и тот же хедер). Иконки «Сообщения»/«Избранное» — раньше гасли на белом фоне (цвет был рассчитан под старый тёмный хедер) — перекрашены в `--color-ink`. Эти иконки теперь показываются и гостям (раньше рендерились только при токене); клик по «Избранное» гостем уводит на `/auth` через уже существующий гейт страницы.
16.5. **Мобильные быстрые чипы-фильтры (`CatalogQuickFilters`) убраны из мобильной версии каталога** — пользователь указал, что это дублирующая механика к кнопке «Фильтры · N» + шторка (`CatalogFilterSheet`), обе решают одну и ту же задачу. Оставлена только кнопка + шторка, ряд отдельных чипов (Марка/Модель/Год/до N л.с.) удалён из JSX и импорта на странице каталога.

16. **«Написать в чат» для авторизованных** — модалка «Подтвердите заявку» больше не показывается для этого действия (только для «Оставить заявку»). Клик сразу создаёт заявку на бэкенде и переводит в `/messages?chat=...`, без лишнего шага. Сделано и в каталоге, и в карточке авто.

17. **Карточка авто — доводка по макетам 03 (мобайл) / 34 (десктоп)**, по фидбеку «страницу авто нужно привести в соответствии с дизайном, сейчас там много упущений»:
    - Хлебные крошки на карточке авто теперь скрыты на мобайле (<768px) — остаётся только стрелка «Назад», как в макете 03. На десктопе хлебные крошки остаются (макет 34 показывает текстовую цепочку без стрелки).
    - Убрал задвоение блока CTA («Оставить заявку» / «Написать в чат»): раньше кнопки повторялись в hero-блоке И компактной копией внутри секции «Что проверяем и показываем» — оставил только hero-версию, дубликат-компакт убран как чистый визуальный мусор, не влияющий на функциональность (те же действия остаются доступны в hero-блоке и в sticky-баре снизу на мобайле).
    - Переставил порядок секций под мобайл/десктоп в соответствии с макетом: «Расчёт до вашего города» теперь идёт сразу после hero-блока (было — в самом низу, после «Описания»), затем «Характеристики», «Что проверяем», «Описание», «Рекомендуем», карточка продавца.
    - Убрал задвоенный заголовок «Расчёт до вашего города» (был и как h2 секции, и повторно как заголовок внутри `price-breakdown-card` — предсуществующий баг, не связанный с редизайном, попался на глаза при доводке).
    - **Не стал добавлять**: бейдж «В наличии · Владивосток» на фото (десктоп-макет) — в БД нет поля локации/статуса наличия, бейдж был бы фиктивным. Вертикальную колонку миниатюр с плашкой «+N» на десктопе (сейчас — обычная горизонтальная лента миниатюр, общая для мобайла/десктопа) — визуальный nice-to-have, отложил как менее приоритетное по сравнению со структурными правками.

18. **Мобильный тулбар каталога переделан по присланному скриншоту-референсу** («Страница каталога вот как должна выглядеть в мобильной версии, а вот что по факту получилось»):
    - Добавлена строка поиска «Поиск по каталогу» (переиспользует существующий `q`-параметр — бэкенд/фетч уже поддерживали текстовый поиск, интерфейса просто не было на странице каталога).
    - Вернул чипы `CatalogQuickFilters` (Марка/Модель/Год/Мощность/Топливо/Пробег/Цена), которые до этого убрал по более раннему сообщению «уберём отдельные фильтры» — новый референс явно показывает их вместе с чипом «Фильтры» в ОДНОЙ горизонтальной прокручиваемой строке (это и есть единственная механика, просто чип «Фильтры» — первый элемент той же строки, а не отдельный блок сверху). Технически: `.catalog-qf`/`.catalog-qf__row` переведены в `display:contents` внутри `.catalog-mobile-filters-row` на мобильном, чтобы все чипы (мастер + быстрые) скроллились как один ряд.
    - Заголовок «Каталог автомобилей» больше не тащит за собой «· N» — счётчик вынесен в отдельную строку.
    - Десктоп и мобайл теперь используют РАЗНУЮ группировку (не просто адаптив одного и того же блока): на десктопе заголовок и «Сортировка» — в одной строке, а «N предложений · цены указаны под ключ до Москвы, с растаможкой» — отдельной строкой под ней (макет 33); на мобильном — «N предложений» и сортировка (без подписи «Сортировка», без рамки, просто текст+иконка) — в одной строке, но уже после чипов, без заголовка рядом. Реализовано через два набора элементов (`--desktop`/`--mobile` модификаторы), скрываемые через media query — сам `<h1>` при этом только один (не дублируется, для SEO).
    - Задет и исправлен ещё один каскадный CSS-баг того же типа, что был раньше с `.catalog-qf__chip--filters`: модификаторы `display:none/flex` для `.catalog-sort-field--desktop` и переопределение стилей `.catalog-sort-field--mobile` были объявлены РАНЬШЕ базового правила `.catalog-sort-field` в файле — из-за одинаковой специфичности проигрывали более позднему базовому правилу. Перенёс модификаторы после базового блока.

19. **Два бага, найденные по скриншоту-фидбеку**:
    - Слишком большой отступ от хедера на мобильном каталоге — причина: `.catalog-layout` (CSS grid, `gap:1.5rem`) содержит `.catalog-sidebar-col`, который на мобильном пуст (сама панель фильтров внутри уже `display:none`), но сам `.catalog-sidebar-col` не был скрыт — пустой grid-элемент всё равно тянул `gap` перед основной колонкой. Добавил `display:none` для `.catalog-sidebar-col` на `max-width:900px`.
    - Текст выбранных чипов («BMW», «3 Series» и т.д.) становился белым на светлом фоне и терялся — тот же паттерн каскадного бага, что раньше был с `.catalog-qf__chip--filters`: поздний базовый `.catalog-qf__chip { background: var(--color-neutral-200) }` (строка ~9596) перебивал background у `.catalog-qf__chip--active/--open`, объявленный раньше по файлу, а `color:#fff` при этом оставался — итог белый текст на светлом фоне. Продублировал `--active`/`--open` правило после позднего базового блока.

20. **Слайдер цены и формат чисел — правки по референсу**: ползунки слайдера цены сделаны полыми (белая заливка, толстое синее кольцо 5px, диаметр 22px) — моя предыдущая правка (сплошная заливка) была неверной интерпретацией, пользователь прислал точный референс с полыми кружками. Также добавлено форматирование чисел в полях «от»/«до» с пробелами между разрядами (3000000 → 3 000 000) через `formatThousands()` в `CatalogFilterFields.js` — хранится по-прежнему как «сырые» цифры в state, форматируется только для отображения.

21. **Блок «Похожие предложения» в пустом состоянии каталога переделан под виджет карточки авто**: раньше — тесная 3-колоночная сетка (`.catalog-grid--similar`/`.catalog-card--similar`, только цена+заголовок). По просьбе пользователя переиспользовал вёрстку/классы того же виджета «Рекомендуем», что уже используется на карточке авто (`.car-detail-similar__scroller` — горизонтальный скролл, одна карточка почти на весь экран, полный контент: фото/заголовок/марка-модель/цена). Удалил как мёртвый код теперь неиспользуемые `.catalog-grid--similar`/`.catalog-card--similar` (нигде больше не встречались).

22. **Ползунки слайдера цены — уточнение по референсу**: предыдущая правка (полый круг, но 22px + 5px обводка) пользователь забраковал как «некорректно» — на скрине с реального устройства обводка выглядела слишком толстой/задвоенной. Вернул пропорции ближе к исходным: 18px круг + 3px обводка (тонкое чистое кольцо), контейнер/трек уменьшены обратно под этот размер — соответствует присланному референсу.

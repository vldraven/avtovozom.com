# avtovozom.com (MVP)

Локальный MVP веб-платформы агрегатора авто:
- каталог автомобилей с фото;
- детальная страница автомобиля с галереей, характеристиками и описанием;
- фильтры и поиск;
- заявка на расчет;
- админский ручной запуск парсера;
- ежедневное обновление через отдельный parser service.

## Технологии

- Frontend: Next.js
- Backend: FastAPI + SQLAlchemy
- Database: PostgreSQL
- Infra: Docker Compose

## Быстрый старт

1. Убедитесь, что установлен Docker Desktop.
2. В корне проекта запустите:

```bash
docker compose up --build
```

3. Откройте:
- Web: http://localhost:3000
- API docs: http://localhost:8000/docs

## Базовый сценарий

1. Откройте главную страницу.
2. Выполните вход (по умолчанию):
   - `admin@avtovozom.local`
   - `admin12345`
   - `dealer@avtovozom.local`
   - `dealer12345`
3. Нажмите кнопку `Обновить каталог (парсер)`, чтобы создать/обновить объявления.
4. Используйте поиск и фильтры.
5. Нажмите `Подать заявку на расчет` у выбранного авто.

## Новые автомобили

В формах `/staff/new-listing` и `/staff/edit-listing` галочка **«Новый автомобиль»** сохраняет отдельный `is_new`. Она не меняет пробег, даты, цену и обязательность других полей. Для существующих и импортируемых объявлений значение по умолчанию — `false`; при редактировании старым API-клиентом без поля текущее значение сохраняется.

- `GET /cars?is_new=true` — новые, `is_new=false` — с пробегом, без параметра — все. Фильтр сочетается с поиском, остальными условиями, сортировкой и пагинацией.
- `/catalog?is_new=true` открывает каталог новых авто. Бейдж «Новый» отображается на превью и странице автомобиля.
- Главная показывает до 12 активных новых объявлений, свежие сначала. На мобильном новый блок стоит после быстрых действий, перед популярными марками; основной баннер и остальные существующие блоки сохранены; на десктопе — после первого экрана, перед марками. Белая подложка занимает всю ширину мобильного экрана и оформлена отдельной панелью на десктопе. Пустой блок скрыт; «В каталог» открывает отфильтрованный каталог, счётчик на десктопе берётся из API. «Последние поступления» сохраняют общую выборку, включая новые автомобили.

При старте backend автоматически добавляет колонку и индекс, как для остальных полей проекта; SQL также сохранён в `backend/migrations/026_car_is_new.sql`. Изменение аддитивное и допускает повторный запуск. При откате кода колонку и индекс можно оставить, сохранив введённые отметки.

Проверки: из `backend/` — `MEDIA_ROOT=/tmp/avtovozom-test-media python3 -m pytest tests/test_new_cars.py tests/test_car_list_filters.py tests/test_special_offer_rub.py`; из корня — `node --test web/tests/catalogCondition.test.mjs` и `npm --prefix web run build`. Тесты API используют отдельную SQLite с синтетическими данными и подменяют обращения к внешним сервисам.


## Порядок подсказок на сайте

До выбора cookies скрыты плашка чата и предложение установки приложения. После любого выбора чат доступен в свёрнутом виде и открывается только по нажатию. Предложение установки доступно при следующем посещении с сохранённым выбором cookies, не раньше чем через 30 секунд; оно ждёт закрытия чата и не показывается на страницах сообщений, входа и работы с объявлениями. Пока предложение установки открыто, плашка чата скрыта.
